# Third-party resources

The portable application reuses the supplied Model Formatter theme, original 3D renderer and model add-on. Viewer attribution is WWE2K_MDL / PWM Mods. Their bundled resources and any notices present in them are preserved by the release packaging process.

The Windows portable build includes its Python runtime and dependencies. Blender is an external dependency for creating swaps. This repository's `Source/` directory contains the matching application layer; it does not contain separate copies of the original renderer, native model libraries, game models or texture sources.

Use and redistribution of third-party resources remain subject to their respective terms.
